# MEMORY GAME

Juego de memoria desarrollado con **Unity y C#**, basado en el clásico juego de encontrar parejas de cartas.


##Sobre el proyecto

El objetivo del juego es encontrar todas las parejas de cartas utilizando la memoria y completando la partida con el menor número de intentos posible.

Este proyecto fue desarrollado para practicar la creación de videojuegos con Unity, la programación en C# y la gestión de la lógica y estados de una partida.

## CARACTERÍSTICAS

- Sistema de selección y volteo de cartas
- Detección de parejas
- Control del estado de la partida
- Contador de intentos
- Sistema para barajar las cartas
- Reinicio de partida
- Interfaz desarrollada en Unity


## TECNÓLOGIAS

- Unity
- C#
